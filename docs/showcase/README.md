# Galeria do Scarlet-Recomp

Aqui vão ficar as fotos reais do jogo no Windows. A arte atualmente usada no topo do README é do **launcher**, não uma captura de jogabilidade.

## Fotos que queremos mostrar

1. **Jogabilidade** — uma cena externa de Pokémon Scarlet rodando no Windows.
2. **60 FPS** — uma captura com o contador de quadros visível.
3. **Menu F1** — a nova interface clara e seus ajustes.
4. **Controles** — ícones de Xbox e PlayStation aparecendo dentro do jogo.
5. **Launcher** — tela de seleção dos arquivos do jogo.

## Como adicionar

Coloque as capturas reais nesta pasta, com nomes curtos como `gameplay.png`, `fps-60.png`, `f1-menu.png`, `controller-icons.png` e `launcher.png`. Depois, inclua as imagens no README com caminhos relativos, por exemplo:

```md
![Pokémon Scarlet rodando no Windows](docs/showcase/gameplay.png)
```

Não use capturas da base Z-A/LAS como se fossem de Scarlet. Antes de enviar, confira se a foto não mostra chaves, caminhos pessoais, arquivos privados ou dados de saves.

As capturas ainda não foram enviadas. Esta pasta reserva um lugar organizado para adicioná-las depois, sem deixar imagens quebradas na página inicial.
